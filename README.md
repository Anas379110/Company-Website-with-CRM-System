# موقع شركة مع نظام CRM لإدارة العملاء المحتملين
**Corporate Website with Integrated Lead CRM** · التصنيف: ويب / تطبيق

> هذا المشروع خاص بشركة/عميل محدد، والكود المصدري غير منشور.
> Private client work — the source code is not public.

## نبذة عن المشروع
موقع شركة مع خط إدارة العملاء المحتملين وتتبع GA4.

## أبرز النقاط
- سلاسل بريد إلكتروني تلقائية عبر SendGrid API
- GA4 Custom Conversion Funnels + Goal Tracking
- Nginx Gzip + Critical CSS + Lazy Loading

## الدور
مطوّر ويب/تطبيقات: بناء تطبيق الويب من الواجهة حتى الخدمات الخلفية والتكاملات.

## التقنيات المستخدمة
Angular, TypeScript, Node.js, MongoDB, SendGrid, Google Analytics 4, AWS, Docker
